# Personal Expense Tracker

A simple web-based Personal Expense Tracker built using HTML, CSS, and JavaScript.  
It allows users to record their earnings and expenses and automatically calculate the remaining money.

## About the Project

The Personal Expense Tracker helps users keep track of their daily earnings and expenses in one place.

Users can enter their name, add earning details, add expenses by category, and view the total earnings, total expenses, and remaining money.

## Features

- Enter user's name
- Add earning source and amount
- Add expense name and amount
- Select expense category
- View earning list
- View expense list
- Calculate total earnings
- Calculate total expenses
- Calculate total money left
- Simple and easy-to-use interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
